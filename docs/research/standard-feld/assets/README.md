# Standard Feld research assets

This directory contains the exact proposed font asset selected by Phase 2. It is research-contract material, not production application code.

## Selected asset

- Asset: `wsprry-standard-feld-radiolib-5x5-v1`
- Canonical data: [`font/font.json`](font/font.json)
- Manifest: [`font/manifest.json`](font/manifest.json)
- License: [`font/LICENSE-RadioLib.txt`](font/LICENSE-RadioLib.txt)
- Checksums: [`font/SHA256SUMS`](font/SHA256SUMS)

The asset is a canonical JSON transcription of all 64 RadioLib simplified Hellschreiber font records at commit `0795caa41c6350a2f862137cfc22528c2aaad2bc`. It is not the historical Tbs 24a font and must not inherit the prior fldigi/xfhell interoperability result.

## Rights boundary

The upstream RadioLib file is distributed under the MIT License. The retained license text is byte-identical to RadioLib's `license.txt` at the inspected revision. Historical and GPL reference fonts are not copied here.

Generated application screenshots, audio, large captures, third-party binaries, and source archives do not belong in this directory.
