## Invariants to enforce in every applicable slice

| Area | Required behavior |
| --- | --- |
| Evidence | Separate context, terminal outcome, collection health, and optional available calibration provenance. Bind accepted settings to the actual run/frame, not current saved settings. Preserve unavailable values and distinguish requested frequency from realized RF, and advertised dBm from measured output |
| Remote identity | Physical executor, device boot, controller boot, assignment/profile, carrier/trust, and existing job/frame IDs remain distinct. Reassignment cannot relabel old records; controller acknowledgment cannot establish remote completion |
| Protocol | Only `describe`, `snapshot`, and `read`; independent schema major 1; exact descriptor/limits validation; no mutation, generic dispatch, arbitrary filters/paths, credentials, private database reads, or diagnostic/settings dump |
| Framing/bounds | Four-byte unsigned big-endian length plus UTF-8 JSON; 8 KiB request wire ceiling, 16 KiB observation ceiling, 128 KiB full response/snapshot wire ceiling, 32 items/page, 4 KiB position, depth 16, five-second total request deadline. Binary units, serialized escaping/envelopes, and framing count as specified in the plan; no fragmentation/compression |
| Validation | Validate shape before field access. Reject duplicate/extra/missing keys, invalid UTF-8, trailing input, wrong types/ranges/units, unknown versions/operations, inconsistent identities, and oversized documents. Use canonical decimal strings for exact large counters/nanoseconds and closed unavailable reason codes. Errors expose bounded reason codes/safe provenance, never rejected raw payloads or secrets; rejected requests do not advance a position |
| Replay | Stateless reads after a validated opaque boot/stream/policy/sequence position. Expose both oldest-retained starting position and head. Do not clamp an invalid/expired/future position or treat a head/snapshot watermark as durable consumption. Runtime replay is separate from journal traversal and History spool/central acknowledgments |
| Consistency | Snapshot matches its watermark or explicitly reports unavailable/uncertain coverage. No falsely seamless separate snapshot/head reads; sequence ordering and pending handoff/loss are accounted for. Consumer retries are repeatable while retained; reset, eviction, policy/assignment changes, and overrun stay explicit |
| Memory/loss | Trial 256 records/4 MiB retained bytes, whichever binds first, plus separately bounded auxiliary memory. Keep context available with dependent terminals. Loss remains visible through bounded metadata even when a loss item cannot fit. Oversized evidence produces explicit rejection/loss, never truncated success |
| Scheduling isolation | Callback handoff is bounded/nonblocking, with no socket I/O, serialization, journal reads, consumer-owned locks, or wait for reader progress. No new unsafe mutable-state polling. Measure accepted budgets; slow clients, floods, reconnects, and observer shutdown do not occupy control/browser/USB capacity |
| Security | Exact peer UID plus protected paths; no broad-role fallback or group-only authorization. Root remains trusted. One authorized reader/one outstanding request; finite accept, parse, scan, memory, and shutdown work. Refuse extra/stalled peers within the deadline |
| Scope | Linux producer only, no durable archive/collector/service deployment or new Pico capability. Unsupported source is explicit but cannot satisfy a required source gate without acceptance |
