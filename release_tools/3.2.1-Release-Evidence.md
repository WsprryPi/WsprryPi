## Release-note security emphasis follow-up

The engineering and published release notes were revised after publication to lead with the two critical unauthenticated remote-code-execution advisories (CVSS v4.0 9.2/10) and Lee C. Bussy's strong recommendation to upgrade all WsprryPi devices. The notes distinguish the stable application upgrade from the required vendor PHP security updates and serving-worker restarts. Development/Beta and private-LAN devices are included in the PHP update recommendation without prescribing an application downgrade. The application release tag remains at the original released commit; this documentation update does not replace the released source or binaries.
